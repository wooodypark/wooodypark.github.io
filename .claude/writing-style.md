# 블로그 글쓰기 스타일 가이드

## 어투

- **경험 공유형**: "~는 이런 기술이다"가 아니라 "나는 이런 걸 겪었고, 이렇게 해결했다"
- **합니다체가 기본 (그리고 거의 전부)**: 서술의 기본형은 `~합니다 / ~입니다 / ~습니다 / ~했습니다 / ~됩니다 / ~였습니다 / ~있습니다`. **포스트 거의 모든 문장이 합니다체로 끝나야 한다.** "~해요 / ~예요" 같은 해요체는 기본이 아니다
- **친근 어미는 아껴서 — 한 포스트당 손에 꼽을 정도만**: `~거든요 / ~잖아요 / ~더라고요 / ~더군요` 같은 친근 어미는 포스트 전체에서 **2~6번 정도만 등장**한다. 한 단락 안에서 연달아 쓰면 가벼워지고 도배된 느낌이 든다. *결정적인 강조 / 솔직한 회고* 지점에만 한두 번 변주로 쓰기
- **변주용 해요체**: `~해요 / ~예요`는 *개인 의견·회고·강조*에 가끔 쓰는 정도. 본문 서술에서는 쓰지 않는다
- **깔끔히 떨어지는 단정형 `~다`**: 용어 정의·사실 서술·강한 결론 문장은 `~다`로 떨어져도 자연스럽다 ("이걸 X 문제라고 부른다", "답은 이거다")
- 인칭은 **"저 / 제가"**, 팀 맥락이면 **"저희"**
- 완벽한 척 하지 않는다. 고민했던 점, 부족한 점도 솔직하게 쓴다

### 어미 사용 비율 (실제 다른 포스트 기준)

- **합니다체** (`~합니다`, `~입니다`, `~습니다`, `~했습니다`, `~됩니다`, `~있습니다`): **90%+** 압도적 다수
- **친근 어미** (`~거든요`, `~잖아요`, `~더라고요`, `~더군요`): 포스트 전체에서 **2~6번** 수준의 변주
- **해요체** (`~해요`, `~예요`, `~돼요`): 개인 의견·회고에 소량
- **단정형** (`~다`): 결론 강조에 간헐

### 전환 예시 (틀린 톤 → 맞는 톤)

| ❌ 잘못된 톤 | ✅ 맞는 톤 |
| --- | --- |
| 유저가 주문을 누르면 메시지를 보내요 | 유저가 주문을 누르면 메시지를 보냅니다 |
| 복구가 안 돼요 | 복구가 안 됩니다 |
| 이건 X라고 불러요 | 이건 X라고 부릅니다 |
| 저의 선택이에요 | 저의 선택입니다 |
| 문제가 있**거든요** + 그래서 안 되**거든요** + 이렇게 했**거든요** (한 단락에 연달아) | 한 단락에 친근 어미는 최대 1번까지 |
| 모든 문장 끝마다 ~거든요/~잖아요/~더라고요 | 합니다체로 풀고, 친근 어미는 결정적 한두 곳에만 |

### 마무리 섹션 예외

`### 마무리` 마지막 줄의 *독자 초대형*은 컨벤션상 해요체로 닫는다.

예: "~경험 있으시면 댓글로 공유해주시면 너무 좋을 것 같아요!"

## 글의 흐름

큰 틀은 **문제 → 과정 → 해결 → 회고**. 결과만 보여주지 않고 왜 그 선택을 했는지, 다른 대안은 뭐가 있었는지 과정을 보여준다.

마무리는 `### 마무리` 섹션으로. 솔직한 회고 + 독자에게 경험 공유 요청으로 끝낸다.

## 포맷 최소 규칙

- 섹션 제목: `###` (h3), 소제목: `####` (h4)
- 섹션 사이 `---` 구분선
- 코드 블록에 언어 태그, 주석은 한국어
- 영어 기술 용어는 그대로 쓰되 처음 등장 시 한국어 병기: **이벤트 루프(Event Loop)**
- 성능 비교는 다크 테마 HTML 테이블 사용 (기존 포스트의 테이블 스타일 참고)
