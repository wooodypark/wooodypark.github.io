# 블로그 글쓰기 스타일 가이드

## 어투

- **경험 공유형**: "~는 이런 기술이다"가 아니라 "나는 이런 걸 겪었고, 이렇게 해결했다"
- **합니다체가 기본**: 서술의 기본형은 `~합니다 / ~입니다 / ~습니다 / ~했습니다 / ~됩니다 / ~였습니다 / ~있습니다`. "~해요 / ~예요" 같은 해요체는 **기본이 아님**. 모든 문장을 해요로 끝내면 이 블로그 톤이 아니게 된다
- **친근 어미로 경직된 톤 완화**: 연속된 합니다체가 딱딱할 때 `~거든요 / ~잖아요 / ~더라고요 / ~더군요` 같은 친근한 어미를 자연스럽게 섞는다. **이게 이 블로그 어투의 핵심**. 합니다체 + 친근 어미 혼합이 포인트
- **깔끔히 떨어지는 단정형 `~다`**: 용어 정의·사실 서술·강한 결론 문장은 `~다`로 떨어져도 자연스럽다 ("이걸 X 문제라고 부른다", "답은 이거다")
- 인칭은 **"저 / 제가"**, 팀 맥락이면 **"저희"**
- 완벽한 척 하지 않는다. 고민했던 점, 부족한 점도 솔직하게 쓴다

### 어미 사용 비율 (참고)

실제 다른 포스트들의 대략적 비율:

- **합니다체**(`~합니다`, `~입니다`, `~습니다`, `~했습니다`, `~됩니다`, `~있습니다`): 60~70%
- **친근 어미**(`~거든요`, `~잖아요`, `~더라고요`, `~더군요`): 20~30%
- **해요체**(`~해요`, `~에요`, `~돼요`): 5~10% — 소량 변주용
- **단정형**(`~다`): 강조 필요한 곳에 간혹

### 전환 예시 (틀린 톤 → 맞는 톤)

| ❌ 해요체 도배 | ✅ 합니다체 + 친근 어미 |
| --- | --- |
| 유저가 주문을 누르면 메시지를 보내요 | 유저가 주문을 누르면 메시지를 보냅니다 |
| 복구가 안 돼요 | 복구가 안 됩니다 |
| 이건 X라고 불러요 | 이건 X라고 부릅니다 |
| 저의 선택이에요 | 저의 선택입니다 |
| 문제가 있거든요 | 문제가 있거든요 ✓ (친근 어미는 그대로 유지) |
| 잘 안 되잖아요 | 잘 안 되잖아요 ✓ (친근 어미는 그대로 유지) |

## 글의 흐름

큰 틀은 **문제 → 과정 → 해결 → 회고**. 결과만 보여주지 않고 왜 그 선택을 했는지, 다른 대안은 뭐가 있었는지 과정을 보여준다.

마무리는 `### 마무리` 섹션으로. 솔직한 회고 + 독자에게 경험 공유 요청으로 끝낸다. 마지막 문장은 대개 "~해주시면 너무 좋을 것 같아요!" 정도의 부드러운 초대형으로 닫는다.

## 포맷 최소 규칙

- 섹션 제목: `###` (h3), 소제목: `####` (h4)
- 섹션 사이 `---` 구분선
- 코드 블록에 언어 태그, 주석은 한국어
- 영어 기술 용어는 그대로 쓰되 처음 등장 시 한국어 병기: **이벤트 루프(Event Loop)**
- 성능 비교는 다크 테마 HTML 테이블 사용 (기존 포스트의 테이블 스타일 참고)
